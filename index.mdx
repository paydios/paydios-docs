Paydios is a full-stack merchant payments platform that lets your business accept global payments via cards, digital wallets, cryptocurrency, and local payment rails — all through a single integration. Whether you're building a custom checkout with the REST API, using the PHP SDK in a Laravel app, managing recurring subscriptions, sending professional invoices, or routing payouts to your bank, Paydios gives you one platform to run it all. The merchant dashboard at [merchant.paydios.io](https://merchant.paydios.io/) gives you real-time visibility into transactions, products, API keys, and settings.

## Get started in 4 steps

<Steps>
  <Step title="Create your merchant account">
    Sign up for free at [merchant.paydios.io/sign-up](https://merchant.paydios.io/sign-up). Verify your email and complete your merchant profile to unlock full API access.
  </Step>
  <Step title="Get your API keys">
    Navigate to **Dashboard → API Keys** at [merchant.paydios.io/dashboard/api-keys](https://merchant.paydios.io/dashboard/api-keys). Copy your **Secret Key** for server-side use and note your **Merchant ID** — both are required for API calls.
  </Step>
  <Step title="Integrate with the REST API or PHP SDK">
    Use the REST API directly with any language, or install the official PHP SDK with `composer require paydios/paydios-php`. The SDK handles authentication and request formatting for you.
  </Step>
  <Step title="Go live and monitor in the dashboard">
    Switch to your live API key, process real transactions, and track revenue, orders, and payouts in real time from the merchant dashboard.
  </Step>
</Steps>
