This page walks you through everything you need to go from zero to your first live payment request. By the end you will have a merchant account, a working API key, a product in the system, and a checkout session ready to accept payments. All code examples use the PHP SDK. If you prefer raw REST calls, see the [Authentication](/authentication) guide for `curl` examples.

<Steps>
  <Step title="Create your account">
    Go to [merchant.paydios.io/sign-up](https://merchant.paydios.io/sign-up) and register with your email address. After signing up, verify your email using the confirmation link sent to your inbox, then complete your merchant profile in the dashboard. A complete profile is required before you can process live payments.
  </Step>
  <Step title="Get your API keys">
    In the merchant dashboard, navigate to **Dashboard → API Keys** at [merchant.paydios.io/dashboard/api-keys](https://merchant.paydios.io/dashboard/api-keys).

    You will see two credentials you need:

    - **Secret Key** (`sk_live_xxx`) — used for all server-side API calls. Keep this private.
    - **Merchant ID** — your unique account identifier, required in checkout session endpoints.

    Copy both values and store them securely.

    <Warning>
      Never include your Secret Key in frontend code, client-side JavaScript, or any publicly accessible file. It grants full API access to your account. Use environment variables on your server instead.
    </Warning>
  </Step>
  <Step title="Install the PHP SDK">
    Install the official Paydios PHP SDK with Composer:

    ```bash
    composer require paydios/paydios-php
    ```

    Add your Secret Key to your `.env` file:

    ```env
    PAYDIOS_SECRET_KEY=sk_live_xxxxxxxxx
    ```

    Do not commit your `.env` file to version control.
  </Step>
  <Step title="Create your first product">
    A **product** represents an item or service you sell. Create one using the SDK:

    ```php
    <?php
    require __DIR__ . '/vendor/autoload.php';
    use Paydios\Client;
    
    $pk = new Client(); // reads PAYDIOS_SECRET_KEY from env
    
    $product = $pk->products()->create([
        'name'        => 'My First Product',
        'description' => 'A sample product',
        'status'      => 'published',
        'currency'    => 'USD',
        'unit_amount' => 2999, // $29.99 in cents
    ]);
    
    echo $product['product']['id']; // your new product ID
    ```

    The `unit_amount` field is always in the **smallest currency unit** (cents for USD). A value of `2999` equals \$29.99. Save the returned product ID — you will use it to associate products with checkout sessions.

    <Info>
      You can also create and manage products directly from the merchant dashboard without writing any code.
    </Info>
  </Step>
  <Step title="Create a checkout session">
    A **checkout session** represents a single payment intent. Create one to generate a hosted checkout page your customer can pay through:

    ```php
    <?php
    require __DIR__ . '/vendor/autoload.php';
    use Paydios\Client;
    
    $pk = new Client();
    
    $merchantId = 'your_merchant_id'; // from Dashboard → API Keys
    
    $session = $pk->sessions()->create($merchantId, [
        'amount'      => 2999,         // $29.99 in cents
        'currency'    => 'USD',
        'description' => 'Order #1',
        'source'      => 'custom_php',
    ]);
    
    $sessionId   = $session['session_id'];
    $checkoutUrl = $session['checkout_url']; // redirect your customer here
    ```

    Redirect your customer to `$checkoutUrl` so they can complete payment using their preferred method — card, wallet, crypto, or local rail. Store `$sessionId` to verify the payment status afterwards.
  </Step>
  <Step title="Verify the payment">
    After your customer completes (or attempts) payment, verify the session status on your server:

    ```php
    $result = $pk->sessions()->verify($merchantId, $sessionId);
    
    if ($result['status'] === 'paid') {
        // Payment confirmed — fulfil the order
        echo 'Payment successful!';
    } else {
        // Payment pending or failed
        echo 'Payment status: ' . $result['status'];
    }
    ```

    Always verify payment status server-side before fulfilling an order. Do not rely solely on client-side redirects to confirm payment.
  </Step>
</Steps>
